# Análisis de Vehículos – Aplicación Web

## Contexto
En este proyecto trabajé con un conjunto de datos de anuncios de vehículos en Estados Unidos. La idea fue explorar la información para entender qué factores influyen en el precio de los autos.

## Objetivo
Desarrollar una aplicación interactiva que permita visualizar los datos de forma sencilla y detectar relaciones entre variables como el precio y el kilometraje.

## Desarrollo del análisis
Primero realicé una exploración de los datos (EDA) utilizando Python, donde revisé la calidad de la información y analicé las variables principales.

Después, construí una aplicación web con Streamlit que permite:
- Visualizar las primeras filas del dataset
- Explorar la distribución de precios mediante un histograma
- Analizar la relación entre kilometraje y precio con un gráfico de dispersión

## Resultados
Se pueden observar patrones claros entre el uso del vehículo (odómetro) y su precio, así como la distribución general del mercado.

## Conclusiones
El kilometraje es un factor importante en el valor de los vehículos. Este tipo de análisis puede ayudar a entender mejor el comportamiento del mercado y apoyar la toma de decisiones.

## Herramientas utilizadas

- Pandas  
- Plotly
