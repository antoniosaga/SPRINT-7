# SPRINT-7

Esta aplicación web fue desarrollada utilizando Streamlit para analizar un conjunto de datos de anuncios de vehículos en Estados Unidos.

La aplicación permite:

- Visualizar las primeras filas del conjunto de datos.
- Construir un histograma del precio de los vehículos.
- Generar un gráfico de dispersión entre el odómetro y el precio.

El proyecto también incluye un análisis exploratorio de datos realizado en un Jupyter Notebook llamado `EDA.ipynb`.
